Adaptive Learning Coach — Agent Steps (v2.6)

Step Type Purpose
0 Read Document User uploads their document (no instruction text).
1 Think Document intake — retrieves any URLs/file links via Glean Document Reader.
2 Read Document Loads the reference rubric (101–401 Tech Office Perspective) from SharePoint.
3 Think Persona setup, guard rail, auto-detect scenario type (Customer Conversation / Enablement Session / Collateral), identify sales stage, define rubric levels & evidence rules.
4 Respond Customer Conversation evaluation — guard clause skips if wrong scenario. Scores A1–A4 (Strategy, Discovery, Competitive, Demo/POC), B (Champion Enablement), C (Collateral Usage). 6-section output including Flow & Quality.
5 Respond Enablement Session evaluation — guard clause skips if wrong scenario. Same competency categories but focused on teaching the behavior. Includes Monday Morning Test and Session Flow & Quality.
6 Respond Collateral evaluation — guard clause skips if wrong scenario. Lighter 3-section output: Asset Classification, Strengths & Gaps, Best Use in Customer Conversations.
7 Plan & Execute Resource Index — Brave + Company search. Chicago-style bibliography tied to evaluation gaps. 3 categories (customer-facing, internal-use, external). Staleness labels on resources >12 months old.
