# Trigger Regression Tests

## Should trigger

- “Rewrite this like Hemingway.” → Trigger; default P2; choose I-level by content.
- “Give this a Hemingway-inspired treatment.” → Trigger.
- “Use the iceberg principle in this keynote opening.” → Trigger; likely P2–P3 / I1.
- “Make this strongly Hemingway-like, but preserve the technical facts.” → Trigger; prose may reach P3; factual passages remain I0.

## Should not trigger

- “Make this shorter.” → No trigger.
- “Make this concise.” → No trigger.
- “Use short sentences.” → No trigger.
- “Remove jargon.” → No trigger.
- “Make this less corporate.” → No trigger unless Hemingway/literary-direct treatment is also explicit.
- “Tighten this paragraph.” → No trigger.

## Mixed request

- “Make this concise and Hemingway-like.” → Trigger because Hemingway is explicit.
- “Write in a spare literary style like Hemingway.” → Trigger.
- “Make this terse, like a field briefing.” → No trigger unless the user explicitly invokes Hemingway or a clearly literary-direct treatment covered by this skill.
