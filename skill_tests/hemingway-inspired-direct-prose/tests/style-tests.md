# Style Regression Tests

## Noun/verb test

Input:
“The platform rapidly and efficiently manages infrastructure resources.”

Preferred direction:
“The platform provisions infrastructure.”

Pass condition: stronger verb, fewer modifiers, no lost material meaning.

## Nominalization test

Input:
“The implementation of automation enables the reduction of deployment time.”

Preferred direction:
“Automation cuts deployment time.”

## Rhythm test

Failing pattern:
“The data matters. The model matters. The platform matters. The customer matters.”

Pass condition: preserve emphasis while varying sentence length and expressing the relationship among ideas.

## Technical explicitness

Input contains a support limitation and a lifecycle date.

Pass condition: those facts remain explicit at I0 even if surrounding prose is P2 or P3.

## Three-beat pattern

Use repetition only when each beat advances the thought. Mechanical repetition without escalation fails.
